Projects

Wave

3D audio visualizer

A rippling surface that reacts to music in real time, inspired by the PlayStation 3's music visualizer. Each frame I run an FFT on the audio, split it into bass, mids and treble, and use those bands to shape the mesh, detect beats and drive the bloom lighting. It plays a demo track generated in the browser, your own files, Spotify or the microphone.

Three.js, Web Audio API, Spotify Web Playback SDK, OAuth 2.0 with PKCE, Cloudflare Workers

Firstwords

AI interview practice

Pick a role and get three realistic interview questions, then specific feedback on each answer. The browser never touches the API key: a serverless function builds the prompts, caps every input and rate-limits each visitor, so the endpoint can't be used as a free proxy.

JavaScript, Netlify Functions (Node.js), Anthropic API
